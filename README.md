# Internship Report – Trịnh Tiến Khải (AWS FCAJ 2026)

Báo cáo thực tập dựng bằng Hugo (theme hugo-theme-learn), song ngữ Việt – Anh.

## Chạy trên máy

```bash
hugo server
```

## Đưa lên GitHub Pages

1. Tạo repo `InternshipReport` trên GitHub và đẩy toàn bộ thư mục này lên nhánh `main`.
2. Sửa `baseURL` trong `config.toml` thành `https://<tên-github>.github.io/InternshipReport/`.
3. Vào **Settings → Pages → Source: GitHub Actions**. Workflow `.github/workflows/hugo.yaml` sẽ tự build và deploy.
